# 五分钟开始使用

## 1. 准备环境

你需要：

- 一个支持 Agent Skills 的 AI 编程助手；
- Node.js 与 `npx`，用于安装 Skill；
- Python 3，用于运行安全生成脚本；
- Chrome、Edge、Safari 或 Firefox 等现代浏览器。

## 2. 安装 Skill

```bash
npx skills add XshuiAi/xshui-workspace-builder --skill xshui-workspace-builder -g
```

如果宿主暂不支持通用安装器，请下载仓库，将 `skills/xshui-workspace-builder` 整个目录放进宿主的 Skill 目录。

## 3. 直接说出你的需求

你不需要先理解模板或数据结构，可以直接对 Agent 说：

```text
请用 xshui-workspace-builder 帮我做一个个人工作台。
我是大学生，想把课程、作业、考试和社团安排放在一起。
```

或者：

```text
请用 xshui-workspace-builder 改造我现有的工作台。
我会把现有 HTML 和希望新增的模块发给你。
```

## 4. 回答访谈问题

Agent 会围绕八类信息提问：名称、身份场景、打开时机、模板、模块、按钮操作、数据与隐私、视觉与可编辑要求。通常分 2–3 轮完成，不会要求你一次填写很长的表格。

## 5. 先确认方案

写代码前，Agent 应先给出：

- 页面地图；
- 模块与字段；
- 每个按钮会做什么；
- 数据保存在哪里；
- 第一版明确不做什么。

关键结构不清楚时，Agent 不应自行猜测。

## 6. 打开生成结果

生成项目里有两个重要位置：

- `src/`：可以继续维护的源码；
- `dist/index.html`：可以双击打开的独立 HTML。

日常使用只需打开 `dist/index.html`。需要改功能时，请修改 `src/` 后重新构建，不要直接把 `dist/index.html` 当作唯一真源。

## 7. 先做一次备份

在工作台“归档与备份”页面导出 JSON，并保存到你自己的备份目录。清理浏览器数据、换浏览器或换设备前，请再次导出。

## 常见问题

### 刷新后数据会消失吗？

正常情况下不会。数据保存在当前浏览器的 IndexedDB。但浏览器隐私模式、清理站点数据或更换访问地址可能产生新的存储空间，因此仍需定期导出 JSON。

### 可以直接发给别人共同使用吗？

可以发送 HTML 文件供别人各自在本地打开，但每个人的数据互相独立。多人共同编辑需要账号、权限和云数据库，不属于第一版。

### 可以把它发布成公开网址吗？

可以把生成的静态 HTML 交给网站托管平台，但这是独立的发布步骤，不等于本 Skill 已经提供云端数据或团队协作。
