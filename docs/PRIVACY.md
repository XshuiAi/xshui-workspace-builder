# 隐私与数据边界

## 默认数据位置

工作台的任务、记录、模块配置和图片默认保存在打开页面的浏览器 IndexedDB 中。轻量界面偏好与应急配置保存在 localStorage。

本项目第一版没有账号系统、远程数据库、云端同步或数据分析服务，也不会声称不同设备之间会自动同步。

## 用户需要知道的限制

浏览器通常会把以下情况视为不同的数据空间：

- 不同浏览器；
- 不同浏览器用户；
- 普通窗口与隐私窗口；
- 不同域名、主机名或端口；
- 本地文件与网站托管地址。

清理浏览器网站数据也可能删除 IndexedDB。因此重要数据应定期导出 JSON。

## 备份内容

JSON 备份可以包含：姓名与工作台标题、外观配置、导航顺序、模块配置、用户记录和经过压缩的图片。备份文件由用户自行保存和传输。

导入前会验证格式与版本并显示摘要。完整恢复会先创建本地恢复快照；损坏文件、未知版本和校验失败不会修改当前数据。

## 分享 HTML 时

导出“包含当前配置与数据的 HTML”可能把工作台里的记录和图片写进文件。分享前应先检查并删除不希望公开的个人信息。公开展示用 HTML 和个人日常使用的工作台，建议分别生成。
