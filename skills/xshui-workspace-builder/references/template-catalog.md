# 模板目录

## xiaoshui

- 场景：个人生活与自媒体创作同时管理。
- 视觉：奶油黄、淡紫、暖粉点缀；编辑杂志式标题；首页不含复杂动图。
- 首页入口：进入今日总览、查看自媒体工作台。
- 默认模块：今日总览、收录箱、任务、随手记、人生目标、成长记录、回顾与复盘、灵感与选题、内容项目、发布与复盘、历史归档。

## admin-minimal

- 场景：行政、助理、办公室综合事务。
- 视觉：Apple 式白灰极简、清晰留白、克制蓝色状态提示。
- 默认模块：今日事项、任务优先级、会议日程、通知收集、文件链接、项目推进、工作记录、周报复盘。

## student-campus

- 场景：大学课程、作业、考试、项目和校园事项。
- 视觉：湖水蓝、薄荷绿、浅雾白，截止日期使用暖橙提醒。
- 默认模块：今日学习、课程表、作业截止日、考试倒计时、学习项目、课堂笔记、社团事项、学期复盘。

三个模板共享同一运行时。自定义搭建应重组模块与字段，不另写一套存储或编辑器。
