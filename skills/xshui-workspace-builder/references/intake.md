# 标准 8 问

将问题分成 2–3 轮，每轮最多 3 个。用户已经回答的信息不重复追问。

1. 你的名字是什么？工作台希望叫什么？
2. 你现在的身份或主要工作是什么？
3. 你通常在什么时候打开它？最想解决的一个问题是什么？
4. 三个模板中更接近哪一个：小水生活与自媒体、行政办公、大学生？
5. 首页和侧栏必须有哪些模块？最多先选 8 个。
6. 每个模块要支持哪些真实动作：新增、编辑、完成、筛选、删除、导入、导出？
7. 数据只在本机，还是未来可能需要跨设备或团队？哪些信息属于隐私？
8. 是否有头像、图片、现有页面、字体、配色或明确不要出现的元素？

完成后先输出：页面地图、模块清单、字段表、按钮行为、存储位置、移动端规则、不做事项。用户确认后才生成文件。
