# 老师，我太想进步了

下载此目录中的 `index.html`，用浏览器打开。首次填写目标、阶段与节奏；已有计划可从首页曲线直接进入今日推进、行动清单、记录打卡和复盘。

## 本次修复

- 今日页的目标、阶段和行动链接以紫色下划线呈现，支持键盘访问。
- 编辑模式可修改页面标题、说明、目标标题与完成标准。目标字段同步到目标页、复盘和备份；不会只改展示文字。
- 文字编辑后点击字号、行距或退出按钮不再被失焦重绘打断。
- 所有内页均有图片区域，支持插入、调整尺寸、替换、删除并保存。

## 给 AI 的提示词

请基于上传的 index.html 为我定制个人进步计划，保留配色、首页曲线及快捷节点。先询问姓名、目标、真实起点、截止日期、完成标准、可用时间、阶段成果与记录频率。确认后填写计划，任务初始未完成，打卡与复盘留空。修改应用存储标识以隔离新副本；保留存储、备份和许可声明。逐项测试今日页链接、目标文字跨页面同步、修改文字后立即调字号、每个内页插图与刷新恢复。交付可离线打开的完整 HTML。

## 数据与维护

记录保存在当前浏览器。换设备或清理数据前用“存”导出。网页不会在关闭后主动追问，日历提醒需要自行导入。已有记录不要通过清理浏览器解决兼容问题。

可维护源码在 `src/`。`index.html` 是由这些源码内联 CSS、JS 和配置形成的单文件版本；修改源码后需同步构建产物。通用脚手架的三个基础模板仍保持原有结构，此目录是完整的进步计划示例。
